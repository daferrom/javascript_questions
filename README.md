# JavaScript Questions

A small collection of standalone JavaScript examples for practicing core language concepts and common interview topics.

## Topics

- Callbacks, promises, generators, and deferred scripts
- Classes and classical/prototypal inheritance
- Scope, lexical scoping, and the temporal dead zone
- Primitive values, references, destructuring, rest parameters, and spread syntax
- Sets, weak sets, weak maps, and design patterns
- Output questions and small experiments

Each topic lives in its own directory and generally contains an `index.js` file. Some directories include more than one example.

## Run an Example

Install a recent version of [Node.js](https://nodejs.org/), then run an example from the repository root:

```bash
node promises/index.js
```

Replace `promises/index.js` with the file you want to explore. These examples are intentionally independent and do not require package installation.
